# Indicator skeleton validation, 2026-10-15

The shared `Indicator` presenter passes an actual UP TCG smoke scenario. This
is partial B6 evidence. It does not qualify WM15, hardware providers, SMP port
retirement, a palette registry, precise glyph anchoring, or title-bar placement.

Native executables are built in `aros-build-indicators`, with the shared
`aros-crosstools` toolchain. The production branch combines the integrated
settings base `3273c593e6`, Tiles B2.2 `e9770f2a47` and hover production
`c5943387f6`. The executable and probe run on the explicitly borrowed UP desktop
substrate from `aros-tiles-validation/attempt-013/base-esp`; its bundle and the
copied runtime library inputs are hashed by `indicators_vm/package.py`. The
native and runtime `AppIconQuery` declarations must match before packaging.

The scenario checks malformed updates preserving the previous value, startup
without a provider, lease expiry, recovery, open/hide/quit and missing Settings.
Actual USB keyboard input opens the panel with LCommand B and closes it with
Escape. Actual pointer input closes it outside, opens it through the glyph and
closes it through a second glyph activation. A Settings endpoint holds a
request beyond the source timeout; panel and command processing continue, and
the late reply returns ownership before shutdown.

The collector freezes its script, QMP stream, command, registers, serial, trace,
screenshots and hashes. The packager freezes executable/library inputs. Replay:

```sh
python3 developer/debug/test/workbench/indicators_vm/verify.py \
  ../aros-build-indicators/vm-004/tcg-01
```

## Failed and limited attempts

`vm-001/tcg-01` passed the smaller command/Escape scenario. `vm-002/tcg-01`
failed the second glyph activation: an inactive-window notification closed the
panel before the region message toggled it open. The presenter associates that
dismissal with the glyph activation. `vm-003/tcg-01` failed after adding a
visibility query: the borrowed hover runtime wrote its expanded query structure
into an executable compiled against the older declaration. Aligning production
and runtime headers removes the overwrite; the packager rejects that mismatch.
The failed directories retain their logs and verdicts.

The fallback timing API and screen rectangle query are provided by the
separate Tiles follow-up. Conditional adapters in the presenter use those calls
when the published header supplies them. The measured baseline uses the
last pointer/region observation; movement before delivery and the first glyph
activation after keyboard opening need the geometry API proof. Stopping
publication relies on Workbench's lease, with up to 500 ms of queued-frame
latency; reversible suspension is needed for an immediate explicit fallback.
