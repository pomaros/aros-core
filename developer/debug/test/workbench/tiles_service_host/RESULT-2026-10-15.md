## Implementation

`System/Tiles` reads bounded `.info` ToolTypes, draws toggle, gauge, slider,
value and glyph templates without Zune, and publishes copied AppIcon surfaces.
GET/SET uses asynchronous ARexx messages; ENV uses file notifications. A global
500-ms frame slot limits generation, while presenter visibility suppresses
steady-state covered updates. Initial registration consumes a frame slot.
Separate heartbeats keep unchanged healthy surfaces alive without regenerating
pixels or postponing the frame cadence.

One pending source request per tile and forty slots isolate unavailable sources.
Timeout stops renewal without freeing a message still owned by the recipient.
Late replies reclaim storage without applying expired values. Shutdown defers
while a foreign task retains a request and rejects queued commands during actual
teardown. This is the conventional UP Exec message ownership contract, not an
SMP source-port retirement or kernel-corruption guarantee.

that completed request's dedicated timer signal before rearming it. A fresh
guest run verified the fix; the failing evidence is preserved.
